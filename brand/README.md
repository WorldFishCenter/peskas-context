# Peskas brand kit

The official Peskas logo, and the one place every Peskas app, site, package and document gets it from.

The mark is a tuna made of hexagon cells: many landing records that together make one picture, inside one clear outline. The cells shade from light at the tail to dark at the head, and one coral cell is the eye. The wordmark is "peskas" in lowercase, set in Sora SemiBold and turned into outlines, so it needs no font.

## How it works

`source/` describes the logo; `build.py` makes every file from it; `sync.py` copies the files each repo needs into that repo, as `consumers.json` lists them. Each repo keeps its own copy, so no build depends on another repo, and `sync.py --check` reports any copy that differs from the kit.

- **To use the logo somewhere new:** take the file from the table below. If it is a Peskas repo, add its files to `consumers.json` and run `python sync.py <repo>`.
- **To change the logo:** edit `source/` (the outline and cells in `mark.json`, colours, products), run `python build.py`, look at the results, then run `python sync.py` and commit in each repo. Tracks also needs `npm run assets` for its Android and iOS icons.
- **To check the repos:** `python sync.py --check` (exit 1 if a copy differs or is missing).

`sync.py` needs only Python. `build.py` needs Python 3.10+ with shapely, pillow and playwright (`pip install shapely pillow playwright`, then `python -m playwright install chromium`). The repos are found next to this peskas-context checkout; point `sync.py --dir name=path` at one checked out elsewhere.

Files made by the kit start with a "Generated by peskas-context/brand/build.py" note where the format allows. Don't edit them in a repo: the next sync overwrites them.

## Which file to use

| You need | Use |
|---|---|
| The logo on a light background | `svg/peskas-logo.svg` |
| The logo on a dark background | `svg/peskas-logo-dark.svg` |
| One colour only (print, stamps, embroidery) | `svg/peskas-logo-ink.svg` (navy) or `svg/peskas-logo-white.svg` |
| The tuna alone, where the logo doesn't fit | `svg/peskas-mark.svg`, `-dark`, `-ink` or `-white` |
| A picture, not a vector (email, slides, Word) | `png/peskas-logo-480.png` or `-1200.png`, and the `-dark` versions; transparent background |
| The logo in a React app | `code/peskas-logo.tsx` (or `.jsx`): `PeskasLogo` and `PeskasMark`, with `code/peskas-logo*.css` for the colours |
| Browser tab icons | `favicon/favicon.svg`, `favicon/favicon.ico` (16, 32 and 48px), `favicon/favicon-96x96.png` |
| Home-screen icon on a phone | `favicon/apple-touch-icon.png` (180px, navy) |
| Icons for an installable web app (manifest) | `app/icon-192.png`, `app/icon-512.png` (`purpose: any`); `app/icon-192-maskable.png`, `app/icon-512-maskable.png` (`purpose: maskable`) |
| Android and iOS app icons and splash screens | `native/` (the sources `@capacitor/assets` expects) |
| A link preview (Open Graph, X/Twitter) | `og/<product>.png` for a product, `social/peskas-social-1200x630.png` for Peskas itself |
| The GitHub repository preview | `social/peskas-social-1280x640.png` (Settings › Social preview) |
| An R package logo | `r/hex-<name>.png` as `man/figures/logo.png` |

Prefer the SVG files wherever they work: they stay sharp at any size.

## Colours

| Name | Light background | Dark background | Used for |
|---|---|---|---|
| Tail | `#a9d1d4` | `#3a6c77` | the tail |
| Body | `#5aa8af` | `#3f8a93` | the cells behind the gills |
| Sea teal | `#006d77` | `#8ccbd0` | the middle of the body |
| Head | `#0b2233` | `#ffffff` | the head cells and the wordmark |
| Eye | `#d96c50` | `#e69f8d` | the eye |

Navy `#0b2233` is the background of the dark versions, the app icons and the cards. At 48px and below (tab icons) the kit draws a simpler tuna, without the gaps between cells, and darkens the tail (`#5aa8af`, `#2f8f97`, `#006d77`, `#0b2233` on light; `#5aa8af`, `#7fbfc5`, `#b5e0e3`, `#ffffff` on dark), so it stays a clear fish at 16px. App icons on navy use the dark small-size colours.

## Using it well

- **Space around it.** Keep empty space around the logo at least half its height on every side.
- **Smallest size.** The logo no smaller than 100px wide on screen (25mm in print). Below that, use the tuna alone, down to 24px tall; below that, the tab icons.
- **Background.** The light versions on white or light backgrounds, the dark versions on navy or dark backgrounds. On a photo or a busy background, use one of the one-colour versions.
- **Don't** stretch it, rotate it, recolour cells, rearrange or drop cells, add shadows or outlines, or set "peskas" in another typeface.

## In apps and sites

The logo is the same everywhere; what follows it says which Peskas product it is.

- **Top bar.** The full logo, 28px tall, then the product's public name in the app's own font, about 16px, medium weight, muted: "peskas Zanzibar", "peskas Tracks". The name sits on the wordmark's baseline, 79.4% of the logo's height from its top. Below 640px wide the tuna alone (28px tall) takes the logo's place. The logo and name are one link to the home page; the SVG has `role="img"` and `aria-label="Peskas"`, so the link reads "Peskas Zanzibar". A crowded bar can step down to 24px and 14px (the Management Platform does, for its Swahili and Portuguese menus).
- **Light and dark themes.** `PeskasLogo` and `PeskasMark` colour their cells with the classes `peskas-fill-1` to `peskas-fill-4` and `peskas-fill-eye`, which read the CSS custom properties `--peskas-1` to `--peskas-4` and `--peskas-eye`. Import the matching CSS file once in the app's entry: `peskas-logo.css` (light only), `peskas-logo.dark-class.css` (`.dark`), `peskas-logo.bs-theme.css` (`[data-bs-theme="dark"]`) or `peskas-logo.data-theme.css` (`[data-theme="dark"]`).
- **Browser tab and home screen.** `favicon.ico`, `favicon.svg` and `apple-touch-icon.png`, linked as:

  ```html
  <link rel="icon" href="/favicon.ico" sizes="32x32">
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">
  ```

  `favicon.svg` follows the browser's light or dark colour scheme by itself. A Next.js app uses its file conventions instead: `app/favicon.ico`, `app/icon.svg` and `app/apple-icon.png`.
- **Link previews.** The product's `og/<product>.png` as `og:image` with an absolute URL, plus `twitter:card` set to `summary_large_image`.
- **READMEs.** Above the title, the logo in its light or dark version to match the reader's GitHub theme, from files in the repository:

  ```html
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset=".github/images/peskas-logo-dark.svg">
    <img src=".github/images/peskas-logo.svg" alt="Peskas" height="48">
  </picture>
  ```

  R packages use their hex instead, on the title line as R packages do: `# Peskas Kenya data pipeline <img src="man/figures/logo.png" align="right" height="139" alt="" />`. pkgdown finds the same file by itself and shows it beside each page's title; its favicons go in `pkgdown/favicon/` (`favicon.ico`, `favicon.svg`, `favicon-96x96.png`, `apple-touch-icon.png`, `site.webmanifest` and the manifest's icons).

## How the files are made

The shapes are exact: the tuna's outline is a few Bézier curves, the cells a regular hexagon grid cut to it, and the wordmark's outlines are placed where Chrome sets "peskas" in Sora SemiBold at 80px with −0.035em letter spacing. `build.py` draws everything from those, and renders the PNG, ICO, cards and hexes with Chrome (Playwright) and Pillow.

Sora is by the Sora Project Authors under the SIL Open Font License 1.1 (`source/fonts/OFL.txt`), which allows its outlines in a logo.
